GitHub + Netlify Publishing Steps

How hosting & updating works:

Your site code lives in GitHub, and Netlify hosts the site for free. Data updates are handled by Google Sheets—editing rows in Google Sheets automatically updates your live Netlify website upon page refresh!

1. Push Code to GitHub

Create a repository named critical-minerals-tracker on GitHub and upload index.html.

2. Deploy on Netlify

  1. Log in to Netlify using your GitHub account.
  2. Click Add new site > Import an existing project > GitHub.
  3. Select your critical-minerals-tracker repo.
  4. Click Deploy Site.
